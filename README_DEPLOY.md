# 🌐 Deploy Website - Cho người khác truy cập

## ⚡ Cách nhanh nhất (5 phút)

### 1. Push code lên GitHub
```bash
git push origin main
```

### 2. Deploy lên Vercel
- Vào: https://vercel.com/new
- Import GitHub repo
- Add environment variables
- Deploy!

### 3. Lấy link public
- Link: `https://your-app.vercel.app`
- **Chia sẻ link này!** ✅

---

## 📚 Chi tiết

Xem file `DEPLOYMENT_GUIDE.md` để biết:
